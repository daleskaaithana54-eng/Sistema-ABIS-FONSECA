# Sistema-ABIS-FONSECA
Este proyecto fue realizado en Python para un restaurante. En el cual permite administrar las diferentes operaciones del mismo restaurante mediante modulos independientes y asi facilitar el registro, consultas, busquedas, modificaciones y la eliminacion de informacion.

Archivos:
main.py: Ejecuta el sistema y permite acceder al menu principal.
menu.py: Menu principal y conecta los modulos del sistema.
ventas.py: Realiza las operaciones relacionadas con las ventas.
productos.py: Registra, muestra, busca, actualiza y elimina producto.
clientes.py: Registra, consulta, busca, actualiza y elimina clientes, ademas cuenta registros.
ingresos.py: Gestiona los ingresos, registra, consulta, busca, modifica, elimina y genera resumen.
archivos.py: Tiene las funciones para leer, guardar y sobreescribir informacion en archivos de texto.

Este sistema tambien utiliza archivos .txt para poder almacenar los datos que se registran para poder guardar la informacion.

Herramientas utilizadas:
